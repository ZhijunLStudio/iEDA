# 固定原生内核依赖

本插件的 GP 暂停/恢复要求 `live_instance_materialization_v2` 检查点语义。源码补丁记录于 `checkpoint-materialization.patch`，确切源文件和已验证二进制哈希见 `validated-kernel.json`。

修复将“发布的实例几何”和 Nesterov 求解器历史分别保存；零步恢复还刷新独立拓扑缓存。旧检查点会明确拒绝，不能静默混用。该补丁已经用于编译本轮所有实验使用的冻结内核。

补丁基于指定的冻结内核源码，不是当前两个工作区的通用补丁。agent 工作区的原生源码更早，parity 工作区另有 EGR 修改；研究运行通过 suite.json 显式固定已验证二进制，不能自动换成任意现有 build。这里提供完整可审查的最小原生修复及来源，未改写两个工作区已有的原生修改。

仅暴露拥塞模式0/3/4。模式5/6的密度屏障暂停状态问题没有在本轮修复，因此不开放。直接 RUDY 交换由 Python 事务后端实现，使用原生导出的几何并由原生指标重新验证。
