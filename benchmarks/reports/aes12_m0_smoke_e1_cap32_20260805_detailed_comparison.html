优化路线

P0 测量可信度

  1. iRCX/SPEF 回标 STA
  2. 清零 unconstrained endpoint
  3. 接入 VCD/SAIF
  4. 修复 congestion -1
  5. 接通 iPNP/iIR

P1 DRC 闭环

  1. 按 violation type 建回归
  2. 扫描 1/3/5 轮详细布线
  3. 校准 track/via/rule
  4. DRC clean 成为 GDS gate

P2 PPA 优化

  1. 利用率/留白/拥塞权重 DOE
  2. CTS 多目标调参
  3. 逐阶段 PPA delta 门禁
  4. 跨 PDK 使用归一化指标

P3 Agent 闭环

  1. JSON 观测面与有限动作
  2. Pareto archive
  3. 输入/工具 hash 追踪
  4. holdout design 验证

完整证据、每项 DRC 主类、门禁定义和数据链接见 Markdown 报告；机器数据见 JSON / CSV。
