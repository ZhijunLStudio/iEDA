## 🔧 调试技巧

### 快速诊断方法
```bash
# 1. 检查LEF是否正确加载
grep "Read LEF" workspace/result/iFP.log

# 2. 检查netlist是否正确读取
grep "Processed.*components" workspace/result/iFP.log

# 3. 检查是否有错误
grep -i error workspace/result/iFP.log

# 4. 检查是否生成DEF
ls -lh workspace/result/*.def

# 5. 检查层名是否匹配
grep "routing_layer.*do not exist" workspace/result/iFP.log
```
