## Technical Details

### Algorithm (Current - Grid Placement)

1. **Macro Collection**: Scans `Design::get_instance_list()`, filters `Cell::isMacro() && !isFixed()`
2. **Grid Layout**: Places N macros in ⌈√N⌉ × ⌈√N⌉ grid within core boundary
3. **Legality Check**:
   - All macros within `Layout::get_core_shape()`
   - No pair-wise overlaps (Rectangle intersection test)
4. **Metric**: `packed_frac = Σ(overlap_area) / Σ(macro_area)` (target < 10%)

## Known Limitations (Step 1)

These are **expected** and will be addressed in Steps 2-3:

1. **No optimization**: Grid placement ignores net connectivity
2. **No channel awareness**: Does not reserve routing space between macros
3. **No timing-driven**: Does not consider critical paths
4. **Fixed spacing**: Grid cells equally sized (no adaptive spacing)
5. **No SA/force-directed**: Current algorithm is deterministic grid

**Why this is acceptable for Step 1:**
- Primary goal: Fix "fake success" (DONE ✅)
- Secondary goal: Provide legal initial placement (DONE ✅)
- Optimization quality: Defer to Step 2 (force-directed) and Step 3 (SA)
