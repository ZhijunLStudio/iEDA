# RFC-20260730-C-VIO — iDRC → iRT 违例反馈契约（草案）

| 字段 | 值 |
|---|---|
| 契约 ID | C-VIO |
| 作者 | A0（预热）/ A5+A6 ACK |
| 状态 | **accepted-draft**（双方 ACK；机读写出已合入，缺省 OFF） |
| 目标 Wave | Wave-1（WP-DRC-01 / WP-RT-01） |

## 变更动机

AES12@65% DRC 1.5万–5.6万；iRT 外环需按违例类型选择 escalate 策略。当前缺统一、机读的 violation 载荷。

## 载荷 Schema（v0 提案）

```json
{
  "schema": "c-vio/v0",
  "design": "aes_sky130_a",
  "rule_deck_hash": "<sha256 or unknown>",
  "violations": [
    {
      "id": "v000001",
      "type": "metal_short|parallel_run_length_spacing|minimum_area|nonsufficient_metal_overlap|other",
      "layer": "met1",
      "bbox": [0, 0, 0, 0],
      "net_ids": ["netA", "netB"],
      "severity": 1.0,
      "source": "idrc_in_design"
    }
  ],
  "summary": {
    "by_type": {},
    "by_layer": {},
    "total": 0
  },
  "coverage": {
    "checked": [],
    "skipped": [],
    "unsupported": []
  }
}
```

## 兼容性

- Wave-0 不强制生产；仅冻结字段名供 A6 实现与 A5 消费。
- 未知 type 归 `other`，不得丢弃。

## 回滚

关闭 iRT 对 C-VIO 的读取，回退到仅 violation count。
